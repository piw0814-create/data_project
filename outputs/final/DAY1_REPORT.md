# DAY1 — 초기 충·방전 기록을 이용한 배터리 수명 예측 설계

EDA와 초기 모델 설계 기록. 실제 모델 개발·평가는 [DAY2 보고서](../day2/DAY2_REPORT.md)에 정리했다.

## 1. 분석 목적과 데이터 정의

초기 100사이클의 기록으로 배터리의 최종 수명을 예측할 수 있는 신호를 찾는다. 수명 예측은 배터리별 사용 가능 기간을 판단하는 참고 정보를 제공할 수 있다. 실제 ESS 운전 환경에서의 성능은 아직 평가하지 않았다.

데이터는 Batch1·2·3이며, 분석 단위는 배터리 셀 1개다. 같은 cell_id라도 배치가 다르면 다른 셀이다. 원본의 셀×사이클 기록을 초기 특징으로 집계하여 셀별 한 행으로 구성한다.

| 배치   | 전체 셀 | 수명값 존재 | 수명 결측 |
| ------ | ------: | ----------: | --------: |
| Batch1 |      46 |          46 |         0 |
| Batch2 |      47 |          39 |         8 |
| Batch3 |      46 |          44 |         2 |

수명과 연결하는 그래프·상관 분석은 수명 결측을 제외한 46·39·44개 셀로 통일했다. 결측 수명을 평균이나 마지막 사이클 번호로 대체하지 않는다. 수명값의 존재와 최종 EOL 레이블의 검증은 구분한다. 이후 DAY2에서 연속 실험·미완료 셀 10개를 제외해 Batch1 모델링 집합은 36개가 됐다. 아래 46셀 통계는 제외 전 탐색 결과이며, 검증된 최종 수명만의 통계로 해석하지 않는다.

본 문서는 주피터 실행 결과를 바탕으로 **그래프 → 확인한 사실 → 해석 → 모델 설계 결정**을 정리한다. 관찰된 관계를 인과관계나 실제 모델 성능으로 표현하지 않는다. 그림은 기존 실행 결과이며, 핵심 결론 도출을 위해 추가로 전체 데이터를 재분석하지 않았다.

## 2. Q1 — 배치가 바뀌면 수명 분포도 달라진다

**확인 목적:** 예측 대상의 범위와 배치 간 차이를 파악한다.

![배치별 수명 분포와 장·단수명 비율](figures/q1_life_distribution.png)

| 배치   |    평균 | 중앙값 | 최소~최대 |    단수명 <500 |   장수명 >1000 |
| ------ | ------: | -----: | --------- | -------------: | -------------: |
| Batch1 |  844.72 |  858.5 | 534~1227  |      0/46 (0%) | 10/46 (21.74%) |
| Batch2 |  565.74 |  472.0 | 392~1186  | 28/39 (71.79%) |   3/39 (7.69%) |
| Batch3 | 1059.66 | 1005.5 | 541~1935  |      0/44 (0%) | 23/44 (52.27%) |

**확인한 내용:** Batch1은 중간 수명대, Batch2는 짧은 수명대에 집중된다. Batch3는 긴 수명 셀이 많고 범위도 넓다. Batch2의 긴 수명 셀들은 newstructure 표시 집단과 연결되어 있다.

**짧은 셀의 단서:** Batch1 최단 셀 20·21은 같은 5.4C(80%)-5.4C 정책이며 수명은 534·559다. Batch2 최단 셀에는 6C(60%)-3C 및 3.6C(9%)-5C 정책이 나타났다. 짧은 수명을 측정 이상치로 확정하지 않고 정책·열화 곡선·실험 집단의 영향 후보로 해석한다. 원인을 분리하여 입증한 것은 아니다.

**모델 설계 결정:** Batch1에는 500 미만 사례가 없으므로 Batch2의 단수명 영역에서 오차가 커질 수 있다. 전체 오차뿐 아니라 수명 구간별 오차를 확인하고, 배치별 평가를 구분한다. 이 예측 범위 문제는 CV 성능 하나만으로 해결되지 않는다.

## 3. Q2 — 열화는 일정한 속도로 진행되지 않는다

**확인 목적:** 초기 용량과 이후 감소 속도 중 무엇이 수명 차이를 설명하는지 살펴본다.

![수명값이 있는 전체 셀의 QD 열화 곡선](figures/q2_capacity_curves.png)

**확인한 내용:** 초기 곡선은 같은 배치 안에서 많이 겹치지만 이후 서로 갈라진다. 많은 셀에서 완만한 감소가 후기의 빠른 감소로 바뀐다. Batch2 다수 셀은 약 400~500사이클 부근에 0.88 Ah 아래로 감소하고, Batch3에는 용량을 오래 유지하는 셀이 많다.

| 배치   | 초기 감소 속도 중앙값 | 후기 감소 속도 중앙값 |
| ------ | --------------------: | --------------------: |
| Batch1 |                0.0014 |                0.0900 |
| Batch2 |               −0.0022 |                0.1886 |
| Batch3 |                0.0015 |                0.0909 |

단위는 Ah/100사이클이며 선형 기울기로 요약했다. 초기는 10~100사이클, 후기는 각 셀의 기록 마지막 100사이클이다. 양수는 감소, 음수는 증가 추세를 뜻한다. Batch2의 초기 증가를 손상 회복으로 해석하지 않는다. 기록 끝이 EOL 전인 셀은 후기 구간도 최종 열화 구간과 다를 수 있다.

**Knee 관찰:** 감소가 더 가파르게 바뀌는 부근을 knee 후보로 보았다. Batch1은 여러 셀에서 약 400~800사이클 부근, Batch2는 많은 셀에서 약 200~400사이클 부근에 가속되는 모습이다. Batch3는 가속 시점이 다양하며 일부 장기간 유지 셀은 약 1500사이클 이후에 가속한다. 이는 육안 관찰 범위이며 정확한 knee 위치를 자동 추출한 결과가 아니다. Knee는 0.88 Ah 도달 지점과 구분한다.

**모델 설계 결정:** 초기 용량의 크기보다 초기 변화량·감소 기울기를 후보로 검토한다. 후기 knee와 후기 감소 속도는 현상 해석에 사용하며, 초기 100사이클 예측의 입력에는 포함하지 않는다. 시간에 따른 열화 곡선의 비선형성만으로 수명 회귀에 반드시 비선형 모델이 필요하다고 결론 내리지는 않는다.

## 4. Q3 — 초기 ΔQ 변화는 수명 차이를 보여주는 특징 후보다

**확인 목적:** 초기 총용량에서 잘 드러나지 않는 방전 곡선 변화가 수명과 연결되는지 확인한다.

공통 전압 그리드에서 `ΔQ(V) = Q100(V) − Q10(V)`를 계산했다. 배열 위치는 실제 summary.cycle 번호로 연결했다. ΔQ는 같은 전압에서의 누적 방전량 차이이며, 분산은 전압 위치마다 그 변화가 얼마나 다른지 요약한다.

![세 배치의 최단·최장 수명 셀 ΔQ 비교](figures/q3_delta_q.png)

| 배치   | 대표 짧은 셀: 수명 / 로그 분산 | 대표 긴 셀: 수명 / 로그 분산 |
| ------ | ------------------------------ | ---------------------------- |
| Batch1 | 534 / −3.367                   | 1227 / −4.648                |
| Batch2 | 392 / −3.292                   | 1186 / −4.449                |
| Batch3 | 541 / −3.452                   | 1935 / −4.342                |

Batch1·3에는 <500 셀이 없어 제공된 수명값 기준으로 각 배치의 상대적인 최단·최장 셀을 비교했다. Batch1 대표 셀 4(제공값 1227)는 후속 기록 연결이 필요한 셀이므로 DAY2에서 제외했다. 이 그림은 당시 탐색 기록이며, 해당 값이 완전한 EOL임을 확인한 것은 아니다.

**확인한 내용:** 세 배치의 대표 짧은 셀에서 ΔQ가 더 깊게 음의 방향으로 내려가며 분산도 크다. 전체 셀의 로그 분산–수명 상관도 각각 −0.886, −0.902, −0.702였다. Batch2의 전체 관계에는 실험 집단 차이도 포함된다.

**해석:** 초기 곡선 변화에 이후 수명을 구분하는 정보가 있을 수 있다. 특정 전압에서 손상이 발생했다거나 분산이 물리적인 손상량이라는 뜻은 아니다. ΔQ 평균과 최솟값도 유용하지만 로그 분산과 정보가 많이 겹친다.

**모델 설계 결정:** 로그 ΔQ 분산을 대표 특징으로 선택하여 단일 특징 선형 회귀부터 비교한다. 이후 추가 특징이 실제 예측을 개선하는지 확인한다. 원 논문도 초기 방전 곡선 차이의 분산을 예측 지표로 사용했다. 논문의 성능을 이번 분석 성능으로 제시하지 않는다. [Severson et al., 2019](https://www.nature.com/articles/s41560-019-0356-8)

## 5. Q4 — 첫 단계 C-rate만으로 수명을 설명하기 어렵다

**확인 목적:** 정책별 수명 차이를 확인하고 충전 조건을 어떤 입력으로 표현할지 정한다.

![Batch1 정책별 평균 수명과 편차](figures/q4_policy_batch1.png)

![Batch2 정책별 평균 수명과 편차](figures/q4_policy_batch2.png)

![Batch3 정책별 평균 수명과 편차](figures/q4_policy_batch3.png)

**확인한 내용:**

- Batch1의 8C(15%)-3.6C는 평균 약 1000사이클, 8C(35%)-3.6C는 약 600사이클이다. 같은 첫 단계 전류와 두 번째 단계 전류에서도 전환 SOC에 따른 차이가 보였다.
- Batch2에서는 같은 전류·전환 SOC 표기에서도 newstructure 집단의 평균 수명이 훨씬 길다. 표시 집단 9개는 평균 941.6, 미표시 집단 30개는 453.0이었다. 표기가 구체적으로 어떤 변경인지 아직 확인하지 않았다.
- Batch3에서는 4.8C(80%)-4.8C가 가장 긴 평균 수명을 보이고, 3.7C(31%)-5.9C는 가장 짧았다. 첫 단계 전류가 낮다는 이유만으로 장수명을 기대하기 어렵다.

정책명의 첫 전류 C1·전환 SOC·두 번째 전류 C2를 추출하여 비교했다. 실제 전류 시계열 I의 파형을 별도로 분석한 결과는 아니다.

| 상관                   | Batch1 | Batch2 | Batch3 |
| ---------------------- | -----: | -----: | -----: |
| C1–수명                | −0.580 | +0.191 | −0.083 |
| 전환 SOC–수명          | +0.235 | +0.116 | +0.541 |
| C2–수명                | −0.096 | −0.116 | −0.043 |
| C2–초기 용량 감소 속도 | +0.527 | +0.339 | +0.708 |

**해석:** 충전 조건은 초기 용량 변화와 관련이 있지만 수명 관계는 배치마다 다르다. SOC의 의미도 전류를 낮추는 전환인지 높이는 전환인지에 따라 달라진다. 조건별 표본이 적고 다른 조건이 함께 변하므로 독립적인 인과효과로 확정하지 않는다.

**모델 설계 결정:** C1·전환 SOC·C2를 함께 표현하는 보조 특징 후보로 둔다. 정책만으로 모든 셀의 수명을 설명하려 하지 않고 ΔQ·온도 등 실제 반응 정보와 비교한다. newstructure는 의미를 확인하기 전까지 집단 해석 정보로 유지하며, Batch1에 없는 집단의 효과를 학습했다고 주장하지 않는다.

## 6. Q5 — 강한 신호는 대표로 선택하고 중복 입력은 줄인다

**확인 목적:** 초기 특징 중 수명과 관련된 후보를 찾고, 입력끼리의 중복을 줄인다.

![초기 특징과 수명의 배치별 상관](figures/q5_feature_correlation.png)

히트맵은 기존 주피터 실행 결과의 상관계수를 재표현한 그림이다. 결측이 있는 특징은 유효한 값이 있는 셀로 계산되므로 Batch2 IR은 33개 셀 기준이다.

**확인한 내용:** ΔQ 계열은 세 배치에서 방향이 같고 강한 관계를 보였다. 충전시간 중앙값은 +0.744/−0.919/+0.638로 방향이 달랐고, 온도·IR·초기 감소 기울기도 배치별 관계가 달랐다. QD 평균과 표준편차는 상대적으로 약한 관계를 보였다.

| 중복 후보                    | 확인한 높은 상관                            |
| ---------------------------- | ------------------------------------------- |
| ΔQ 평균–최솟값               | Batch1 0.993, Batch2 0.979, Batch3 0.991    |
| ΔQ 최솟값–로그 분산          | Batch1 −0.947, Batch2 −0.975, Batch3 −0.921 |
| Tavg–Tmax                    | Batch1 0.956, Batch3 0.972                  |
| QD 표준편차–초기 감소 기울기 | Batch3 0.964                                |
| 충전시간 중앙값–로그 ΔQ 분산 | Batch2 0.947                                |

**해석:** 입력끼리 강한 선형 관계가 있으면 선형 회귀 계수의 해석과 안정성이 나빠질 수 있다. 예측 성능이 반드시 나빠진다는 뜻은 아니다. 특히 Batch2의 충전시간과 ΔQ 사이 관계에는 앞서 확인한 실험 집단 차이가 섞여 있다.

**모델 설계 결정:** ΔQ는 로그 분산, 온도는 평균 Tavg를 대표 후보로 선택한다. 추가 특징의 독립적인 개선 효과는 CV로 확인하고, 여러 입력을 쓰는 선형 모델에서는 Ridge를 비교한다. |r|≥0.85는 중복 후보를 찾는 탐색 기준이며 다중공선성의 유일한 판정 기준은 아니다.

## 7. Feature Engineering — 발견에서 입력으로 연결

| 입력             | EDA 근거                                        | 설계상 역할                          |
| ---------------- | ----------------------------------------------- | ------------------------------------ |
| 로그 ΔQ 분산     | 세 배치에서 같은 방향의 강한 관계, ΔQ 계열 중복 | 핵심 특징 F0                         |
| 충전시간 중앙값  | 평균을 크게 올리는 약 3933~3935 기록이 있음     | 안정적인 대표값을 사용하는 추가 후보 |
| 평균 Tavg        | Batch1 수명 상관 −0.482, Tmax와 중복            | 온도 대표 추가 후보                  |
| 초기 감소 기울기 | 초기 용량 변화의 속도 표현                      | 추가 검토 후보                       |
| C1·전환 SOC·C2   | 전류와 전환점을 함께 고려할 필요                | 추가 검토 후보                       |

첫 특징 집합 F0는 로그 ΔQ 분산 하나, F1은 로그 ΔQ 분산 + 충전시간 중앙값 + 평균 Tavg다. 다른 후보를 처음부터 모두 추가하지 않는다. IR과 QD 평균·표준편차는 첫 비교에서 보류한다. 충전시간·온도를 추가하면 반드시 성능이 개선된다고 가정하지 않는다.

모든 입력은 100사이클 완료 시점에 이용 가능한 정보로 구성한다. 후기 감소 속도·실제 knee·최종 수명에서 파생한 값은 입력에 넣지 않는다.

## 8. 회귀 선택과 모델 후보

**Task는 회귀, Target은 최종 cycle_life(사이클 수), 예측 시점은 100사이클 완료 시점**으로 정한다. 몇 사이클까지 사용할 수 있는지를 수치로 예측하려는 목적과 초기 100사이클 ΔQ 분석에 맞는다. 분류보다 성능이 우수하다는 비교를 수행한 것은 아니다.

| 후보 모델      | EDA와 연결한 선택 이유                                                       | 비교 목적                                                 |
| -------------- | ---------------------------------------------------------------------------- | --------------------------------------------------------- |
| 평균 수명 예측 | 배치별 분포가 다르므로 단순한 기준 성능이 필요                               | 학습 셀 평균보다 개선되는지 확인                          |
| 선형 회귀      | 로그 ΔQ 분산의 수명 관계가 강하여 단순한 선형 가설을 먼저 검토할 근거가 있음 | F0·F1을 비교해 대표 신호와 추가 입력의 효과 확인          |
| Ridge 회귀     | 중복 입력이 관찰되고 학습 셀 수가 적어 계수 안정성과 과적합 완화가 필요      | F1의 일반 선형 회귀와 같은 입력으로 비교해 규제 효과 확인 |

Ridge는 계수 크기에 벌점을 주어 큰 계수를 억제한다. 추가 특징 효과와 모델 규제 효과를 구분하기 위해 F1의 일반 선형 회귀도 함께 비교한다. Ridge 규제 강도는 소수 후보(예: 0.1, 1, 10, 100)를 학습 CV에서 비교한다.

현재는 셀별 요약 특징과 적은 개발 표본을 사용하므로 단순한 모델부터 평가한다. 딥러닝이나 많은 모델의 광범위한 탐색을 먼저 수행할 근거는 부족하다. 참고 예시의 LightGBM·Tweedie 설정을 현재 데이터에 그대로 적용하지 않는다. Target은 우선 원래 사이클 수로 예측하며 분포를 바꾸기 위한 로그 변환을 자동 적용하지 않는다.

## 9. 데이터 처리·분할·평가

**현재 처리와 계획:** 수명 결측은 제외, IR=0은 결측 표시, QD·IR·온도·충전시간이 모두 0인 초기 기록은 집계에서 제외했다. 원본은 유지하고 단발 급락·스파이크를 모두 삭제하지 않는다. 정상적인 후기 용량 감소는 열화 신호로 유지한다. 충전시간은 중앙값으로 요약한다. 필요한 결측 대체와 표준화는 Train 또는 각 CV 학습 폴드 안에서만 fit한다.

**레이블 확인:** Batch1 대표 셀 4의 곡선은 기록 종료 시 약 1.02 Ah로 0.88 Ah보다 높았다. 공개 코드에는 일부 Batch1 셀의 연속 실험 병합과 미완료 셀 제외가 있으며, 공개 Batch2 날짜와 로컬 Batch2 날짜도 다르다. 학습 전에 최종 수명과 학습 대상 셀을 확인하고 공개 셀 번호를 그대로 적용하지 않는다. DAY1의 46개는 수명값 존재 수였다. DAY2 레이블 점검 후, 후속 파일이 없어 연결하지 못한 5셀과 미완료 5셀을 제외해 36개로 확정했다. [공식 처리 코드](https://github.com/rdbraatz/data-driven-prediction-of-battery-cycle-life-before-capacity-degradation/blob/master/LoadData.m)

**분할:** 검증된 Batch1 셀을 약 80% 학습 / 20% 보관 평가로 나누고 seed 42를 기록한다. 동일 셀의 사이클을 서로 다른 분할에 넣지 않는다. 학습 부분에서 5-fold CV로 입력과 모델을 선택한다. 선택 이후 보관한 Batch1을 평가하고, 최종 모델을 확정한 뒤 Batch2에서 평가한다. Batch3는 추가 일반화 평가 후보다.

**평가:** 주 지표는 MAPE, 보조 지표는 MAE·RMSE다. 수명 범위가 다르므로 상대 오차와 사이클 단위 오차를 함께 보고한다. 전체 및 배치별·수명 구간별 오차, 장수명 과소 예측/단수명 과대 예측 여부를 확인한다.

**평가 이력:** DAY1 요구에 따라 Batch1·2·3의 레이블 관계를 이미 탐색했다. Batch2·3을 완전히 미열람인 Test로 표현하지 않는다. 이후 모델·특징·튜닝 선택은 Batch1 개발 데이터에서 수행하고, 최종 평가 결과에 맞춰 같은 평가 배치를 반복 사용하여 모델을 고르지 않는다.

## 10. 핵심 제안

초기 총용량이 비슷해도 방전 곡선 변화와 이후 수명에는 차이가 나타났다. 따라서 로그 ΔQ 분산으로 단순 회귀를 시작하고, 충전시간 중앙값·온도의 추가 효과와 Ridge의 규제 효과를 개발 데이터에서 비교한다. 배치별 차이가 커서 다른 배치의 성능도 별도로 확인한다. 이것은 EDA에 근거한 초기 설계다. DAY2에서는 이 제안부터 검증한 뒤 초기 용량 특징·규제·학습 목표·곡선 표현을 비교하고, 충전 프로토콜 분리로 추가 검증했다. 각 시도의 결과와 판단은 [DAY2 보고서](../day2/DAY2_REPORT.md)에 연결했다.
