# DAY2 부록 — 비즈니스 목적을 고려한 추가 실험

본문의 모델 개발·평가를 마친 뒤, 단수명 배터리를 오래 사용할 수 있다고 예측하는 오류를 줄일 수 있는지 추가로 탐색했다. **추가 실험 모델은 최종 추천에 채택하지 않았다.** 전체 프로젝트의 최종 추천은 기존 29셀 단일 분산 선형회귀이며, 아래는 이 모델과 목적별 대안을 비교한 후속 탐색 기록이다. 아래 수치는 이미 여러 번 확인한 Batch2·3의 후속 탐색 결과다.

## 1. 목적과 비교 조건

조기 불량 선별이나 보증 비용 관리에서는 단수명 셀을 놓치는 비용이 클 수 있다. 반면 재사용·자원 활용에서는 수명을 지나치게 짧게 예측하는 것도 낭비를 만든다. 따라서 전체 MAPE뿐 아니라 단수명 셀의 과대예측을 함께 확인했다. 실제 비용 자료가 없으므로 어느 목적이 더 중요하다고 확정하지 않았다.

주 비교는 프로토콜을 분리한 Batch1 학습 29셀·Hold-out 7셀이다. 초기 100사이클 이내의 ΔQ 로그 분산 하나를 입력으로 유지하고, 기존 선형회귀와 다음을 비교했다.

- **수명의 역수 학습:** `1000 / cycle_life`를 열화 속도의 대리값으로 학습했다. 예측 역수가 양수가 되도록 연결 함수를 사용했다. 고정된 종료 기준 아래 수명과 열화 속도가 역관계일 수 있다는 가설이며, 실제 열화가 일정하다는 물리 법칙을 가정한 것은 아니다.
- **분위수 0.5:** 조건부 중앙값을 예측하도록 절대오차 기반으로 학습했다. 기존 최소제곱 선형회귀보다 큰 오차에 덜 민감한 기준이다.
- **분위수 0.3:** 수명을 과대예측하는 오류에 더 큰 비용을 두어 보수적인 예측을 유도했다. 검증된 수명 보증 하한을 의미하지 않는다.

전처리는 각 Batch1 학습 폴드 안에서만 fit했다. 일반 교차검증과, 개발 셀 중 짧은 하위 20%·30%를 검증하고 긴 나머지로 학습하는 두 시나리오를 비교했다. 후자는 같은 프로토콜을 학습에서 제거했으며, 서로 겹치는 검증 집단이므로 독립적인 CV 평균으로 해석하지 않았다.

## 2. 핵심 결과

MAPE는 낮을수록 좋다. 서로 다른 학습 셀 구성의 점수를 같은 조건의 모델 비교로 섞지 않았다.

| 동일한 학습 29셀 모델 | Batch1 CV | Batch1 Hold-out | Batch2 | Batch3 |
| --- | ---: | ---: | ---: | ---: |
| 기존 분산 1개 선형회귀 | 7.93% | 10.73% | 28.68% | 12.09% |
| 수명의 역수 학습 | 8.43% | 8.74% | 30.24% | 13.33% |
| 분위수 0.5 | 7.58% | 10.90% | 26.16% | 12.76% |
| 분위수 0.3 | 8.42% | 12.29% | 25.44% | 14.59% |

![학습 목적에 따른 배치별 오차](business_appendix/business_tradeoff.png)

**분위수 0.3은 단수명 과대예측을 줄였지만 장수명 예측을 희생했다.** Batch2의 500사이클 미만 28셀에서 평균 과대예측량은 기존 145.8사이클에서 128.7사이클로 줄었다. 그러나 28셀 모두 여전히 과대예측했다. Batch3에서는 평균 과소예측이 85.7사이클에서 159.9사이클로 커졌다. 단수명 문제를 해결한 모델이라고 볼 수 없다.

**분위수 0.5는 유효한 대안이었다.** 같은 29셀 분산 기준 모델보다 CV는 **7.93%→7.58%**, Batch2는 **28.68%→26.16%**로 좋아졌다. 반면 Hold-out은 **10.73%→10.90%**, Batch3는 **12.09%→12.76%**로 소폭 나빠졌다. 일반 Batch1 CV는 분위수 0.5, 긴 수명→짧은 수명 검증은 분위수 0.3을 선택했다.

따라서 추가 손실 모델을 채택하지 않은 이유는 **배치와 검증 기준을 함께 만족하는 일관된 개선을 확립하지 못했기 때문**이다. 이는 전체 결과를 본 뒤의 종합 판단이며, 사전에 정한 ‘모든 지표를 개선해야 한다’는 선택 규칙은 아니었다. 분산 모델이 유일한 최적 모델이라는 의미도 아니다. Batch2 상대오차를 더 중시하면 분위수 0.5를 선택할 근거가 있으며, 현재 추천은 Batch3 성능과 기존 기준 모델의 유지까지 고려한 선택이다.

예전 셀 분리의 학습 28셀에서도 분위수 0.5를 비교했다. 기존 모델의 Batch2/3 MAPE **26.19% / 11.94%**가 **23.84% / 12.00%**가 됐다. 다만 Batch1 CV는 9.28%→9.99%, Hold-out은 6.44%→7.31%로 나빠졌다. Batch2 개선은 관측했으나 다른 검증 기준까지 함께 개선하지는 못해 이 후보로 최종 추천을 교체하지 않았다. 본문의 26.19%는 본문 개발 범위의 관측 최저값이며, 이후 모든 탐색을 합친 최저값이라는 뜻은 아니다.

그 밖의 추가 실험은 다음만 남겼다.

- **분포 변환·정렬:** 수명 표준화는 예측 성능을 바꾸지 않았다. 로그·제곱근 변환이나 초기 입력의 CORAL 정렬도 모든 배치를 함께 개선하지 못했다. 예전 28셀 모델의 CORAL 퍼짐 정렬은 Batch2 43.33%, Batch3 13.34%였다. 일부 정렬·가중 방법은 외부 배치의 정답 없는 초기 입력까지 사용했으므로 Batch1만으로 전처리를 fit하는 설정과 구분한다. 분포 그림만 확인한 변환은 성능 실험으로 계산하지 않았다.
- **짧은 수명 방향의 검증:** 검증 기준만 변경해도 분산 하나의 기존 모델이 선택되어 예측은 같았다. 검증 목적을 바꾸는 것만으로 학습에 없는 수명 정보를 확보하지는 못했다.
- **초기 변화 진행 특징:** 10→50과 50→100사이클의 사이클당 ΔQ 변화 분산 비율을 추가했다. 프로토콜 분리에서 Batch2/3는 26.30% / 12.03%였지만, 예전 셀 분리에서는 기존 결과와 거의 같아 학습 셀 구성에 따른 불안정성이 남았다.

## 3. 비즈니스 시사점과 결론

| 목적 | 이번 실험에서 확인한 점 | 실무 적용 전에 필요한 확인 |
| --- | --- | --- |
| 조기 불량 선별·보증 비용 관리 | 보수적 예측은 단수명 과대예측을 줄일 수 있음 | 불량을 놓치는 비용과 정상 셀을 불량으로 판단하는 비용을 함께 평가 |
| 교체 시점 계획 | 점추정만으로 교체 시점을 확정하기 어려움 | 예측 구간·하위 분위수의 실제 포함률과 새 배치에서의 신뢰성 검증 |
| 재사용·자원 활용 | 보수적 예측은 장수명 셀을 너무 일찍 제외할 수 있음 | 과소예측으로 발생하는 사용 가능 수명 손실을 평가 |

**단수명 사례 부족은 Batch2 성능 저하의 유력한 요인 중 하나다.** Batch1에서 배운 관계를 더 짧은 수명에 적용해야 했지만, 배치 간 초기 상태·충전 조건·특징–수명 관계 차이와 각각의 기여도를 분리하지 못했다. 이번 추가 실험에서는 보수적인 예측으로 단수명 오차를 일부 줄였지만, 장수명 예측과의 균형이 남았다.

다음 개선 방향은 **단수명과 다양한 운영 조건의 사례를 학습에 보완하는 것**이다. 학습 범위를 보완하면 짧은 수명 예측이 개선될 가능성이 있으나, 별도 검증이 필요한 가설이다. 운영 목적에 맞는 오류 비용을 정하고, 새 배치에서 개선 정도를 확인하면 좋겠다. 보수적인 점예측은 교체 계획의 참고값으로 활용하고, 수명 보증에 쓰려면 별도로 예측 구간을 검증해야 한다.

원논문의 공식 처리 코드는 처음 두 수집 배치를 합친 집합에서 학습·주 테스트를 분리한다. 이 구성은 우리 과제의 Batch1 학습→Batch2 평가보다 다양한 수명 사례를 학습하는 데 유리했을 것으로 예상한다. 다만 사용 파일·라벨 처리·모델 설정도 달라 9.1%는 참고 기준으로 비교한다. [공식 분할 코드](https://github.com/rdbraatz/data-driven-prediction-of-battery-cycle-life-before-capacity-degradation/blob/master/LoadData.m), [원논문](https://web.mit.edu/braatzgroup/Severson_NatureEnergy_2019.pdf)

추가 개발은 종료하고 작업용 실험 학습 코드·중복 그림·임시 파일은 폐기했다. [평가 수치](business_appendix/metrics.csv), [셀별 예측](business_appendix/predictions.csv), [Batch1 폴드 점수](business_appendix/fold_metrics.csv), [설정·환경·무결성 기록](business_appendix/provenance.json)을 근거로 보존했다. 이 기록은 저장 결과 검산용이며, 폐기한 추가 실험의 재학습 코드는 제공하지 않는다. 본문의 실행 코드와 고정 모델은 유지했다.
